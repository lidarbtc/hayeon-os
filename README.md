# HaYeon OS

A Windows XP/7-style web desktop for tripleS HaYeon.

[hayeon.eth.link](https://hayeon.eth.link)

![HaYeon OS desktop](public/og.jpg)

## Development

Node.js 20.19+ and pnpm.

```sh
pnpm install
pnpm dev
```
